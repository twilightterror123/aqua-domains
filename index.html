Echte Subdomain

Hier wird die Domain tatsächlich an dein Vercel-Projekt übergeben. Dafür müssen VERCEL_TOKEN und VERCEL_PROJECT_ID im Server-Environment gesetzt sein und du musst die Domain kontrollieren.

Einmaliges Setup

01 · VercelVerbinde dieses Repository mit Vercel. Pushes auf main können anschließend automatisch deployen.
02 · SecretsSetze VERCEL_TOKEN und VERCEL_PROJECT_ID ausschließlich als Vercel Environment Variables.
03 · DomainFüge deine eigene Basis-Domain bei Vercel hinzu und richte die von Vercel verlangten DNS-Einträge ein.
AQUA kann keine fremde Domain übernehmen. Für eine echte Subdomain wie app.deine-domain.de brauchst du die Kontrolle über deine-domain.de. Danach kann die API die Subdomain deinem Projekt zuordnen.

Vercel unterstützt Custom Domains und auch Wildcard-Domains. Für größere Hosting-Plattformen gibt es inzwischen Vercel for Platforms mit programmatischer Domain- und Deployment-Verwaltung.
